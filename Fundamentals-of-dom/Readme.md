# 🌐 JavaScript Fundamentals of DOM

Welcome to my **Fundamentals of DOM (Document Object Model)** practice module! This repository contains my practical exploration of how JavaScript interacts with HTML and CSS to create dynamic and interactive web pages.

## 📚 Topics Covered

In this module, I have practiced several essential DOM manipulation techniques:

* **Selecting Elements**: Mastering `getElementById`, `getElementsByClassName`, `getElementsByTagName`, and `querySelector/querySelectorAll`.
* **Traversing the DOM**: Understanding parent-child relationships using `parentNode`, `childNodes`, `children`, `nextSibling`, etc.
* **Manipulating Content**: Changing text and HTML content using `innerText`, `textContent`, and `innerHTML`.
* **Styling via JS**: Dynamically applying CSS styles and managing classes using `classList` (add, remove, toggle).
* **Attributes Management**: Getting, setting, and removing HTML attributes like `src`, `href`, `id`, and custom `data-*` attributes.
* **Creating & Removing Elements**: Using `createElement`, `appendChild`, `removeChild`, and `insertBefore` to modify the document structure.
* **NodeList vs HTMLCollection**: Understanding the differences between different types of element collections.

## 📂 Practice Areas

* **DOM Selectors**: Practice on selecting single and multiple elements.
* **Dynamic UI**: Creating elements on the fly based on user actions or data.
* **Style Injection**: Real-time styling updates through JavaScript.
* **Layout Manipulation**: Modifying the structural flow of the webpage.
