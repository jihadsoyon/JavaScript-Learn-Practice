# 🚀 JavaScript Basic ES6 Practice

Welcome to my **Basic ES6** learning module! This repository contains my practical implementation of modern JavaScript features, focusing on cleaner syntax and more efficient code handling.

## 📚 Topics Covered

Based on my progress in this module, I have explored the following concepts:

*   **Variable Declarations**: Understanding the differences between `var`, `let`, and `const`.
*   **Template Literals**: Creating dynamic strings and generating HTML fragments.
*   **Arrow Functions**: Writing concise functions and performing array transformations.
*   **Default Parameters**: Implementing utility functions with default argument values.
*   **Spread Operator**: Usage with arrays, objects, and function arguments.
*   **Destructuring**: Practical examples of array and object destructuring.
*   **Object Manipulation**: Mastery of `Object.keys`, `values`, and `entries`.
*   **Immutability**: Demonstrating `Object.freeze`, `Object.seal`, and the `delete` operator.
*   **Optional Chaining**: Safely accessing nested properties and object traversal.
*   **Property Access**: Comparing dot notation vs bracket notation.
*   **Loops**: Using `for...in` and other methods for object traversal.
