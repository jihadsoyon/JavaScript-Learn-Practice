# 🧾 Job Application Tracker

A modern and responsive Job Application Tracker web app that helps users organize and monitor their job applications efficiently. Users can add jobs, update application statuses, track progress, and stay productive during their job search journey.

🌐 **Live Website:**  
https://jobb-applicationn-trackerr.netlify.app/

---

## 🚀 Features

- ✅ Add and manage job applications
- 📌 Track application status
- 🔍 Search and filter applications
- 📱 Fully responsive design
- ⚡ Fast and smooth user experience
- 🎯 Clean and user-friendly interface
