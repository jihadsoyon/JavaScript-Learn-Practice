# 💳 PAYOO - Mobile Financial Services (MFS)

A modern Mobile Financial Services (MFS) web application that simulates real-world digital banking operations. PAYOO allows users to securely manage their finances through a clean, responsive, and user-friendly interface.

## 🌐 Live Demo

👉 https://pay00.netlify.app/home.html

---

## 📖 Overview

PAYOO is a smart Mobile Financial Services (MFS) interface built with **HTML, CSS, DaisyUI, and Vanilla JavaScript**. It provides a seamless digital banking experience by allowing users to perform common financial operations such as adding money, cashing out, transferring funds, claiming bonuses, and tracking transaction history.

The project focuses on DOM manipulation, JavaScript logic, event handling, and creating an interactive user experience without using any frontend framework.

---

## ✨ Features

- 🔐 Secure Login Interface
  - Simple authentication with username and password.

- 💰 Add Money
  - Deposit money into your PAYOO account.

- 💸 Cash Out
  - Withdraw money securely using PIN verification.

- 🔄 Money Transfer
  - Send money to another user safely.

- 🎁 Bonus Rewards
  - Claim promotional bonuses and update balance instantly.

- 📜 Transaction History
  - View a complete history of all financial activities.

- 🔒 PIN Verification
  - Every sensitive transaction requires PIN authentication.

- 📱 Responsive User Interface
  - Clean and mobile-friendly design built with DaisyUI.

- ⚡ Dynamic Balance Updates
  - Account balance updates instantly after every transaction.
