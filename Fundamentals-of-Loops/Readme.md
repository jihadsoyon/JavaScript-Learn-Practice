# 🔄 JavaScript Fundamentals of Loops

Welcome to my **Fundamentals of Loops** practice module! This repository contains my exploration of various iteration techniques in JavaScript, focusing on automation and data traversal.

## 📚 Topics Covered

In this module, I have practiced several ways to repeat tasks and iterate over data:

*   **While Loop**: Mastering the basic syntax and structure of while loops.
*   **For Loop**: Deep dive into for loops for controlled iterations.
*   **For...Of Loop**: Learning modern and cleaner ways to iterate over arrays and iterable objects.
*   **Do...While Loop**: Understanding the difference between while and do-while logic.
*   **Loop Control Statements**: 
    *   **Break**: Stopping a loop based on a specific condition.
    *   **Continue**: Skipping current iterations to move to the next one.
*   **Incremental & Decremental**: Practicing both forward and backward looping techniques.
*   **Summation & Logic**: 
    *   Calculating the **Sum** of numbers using loops.
    *   Finding and filtering **Even** and **Odd** numbers.
    *   Using **Modulus** operators within loops for specific logic.
*   **Different Techniques**: Exploring various creative ways to implement looping.
