# ⚡ JavaScript Event Fundamentals

Ekhane ami JavaScript-er DOM Events ebong interactive elements niye ja ja shikhechi ta organize kore rakha hoyeche. Protita file-e alada alada event concept niye practical kaj kora hoyeche.

## 📚 Key Concepts Covered

*   **Event Handlers**: Inline handlers theke shuru kore `addEventListener` er porjonto bibhinno poddhoti.
*   **Event Bubbling**: Multilayered elements-er moddhe event kivabe propagate kore ta handle kora.
*   **Event Delegation**: Dynamic list item ba elements management-er jonno efficient event delegation.
*   **DOM Manipulation**: Button click ba input field-er upor base kore dynamic vabe content add/remove kora.
*   **Keyboard & Mouse Events**: Keyboard typing ba mouse interaction handle korar methods.
*   **Interactive UI Components**: Comment box, delete button validation, ebong status updates-er moto real-world examples.

| File Name | Description |
