# 🧩 JavaScript Problem Solving

Welcome to my **JavaScript Problem Solving** repository! This folder is dedicated to mastering algorithmic thinking and practical logic through a wide variety of programming challenges.

## 📚 Key Concepts & Solutions

In this module, I have implemented solutions for various real-world and algorithmic problems:

*   **Mathematical Operations**: Implementing basic calculators, unit conversions (height/distance), and working with the `Math` object for random number generation.
*   **Logic & Validation**: Handling leap year validation, finding maximum/minimum values among multiple inputs, and variable swapping techniques.
*   **Data Manipulation**: Removing duplicate elements from arrays, calculating averages of odd numbers, and managing JavaScript `Date` objects.
*   **Practical Business Logic**: 
    *   **Discount Systems**: Calculating flat and layered quantity-based discounts.
    *   **Shopping Cart**: Functions for total product cost and cart total calculations.
    *   **Resource Planning**: Wood and clothing cost estimation based on quantity.
    *   **Optimization**: Finding the cheapest or most expensive items from a dataset.
